# Shock Waves in Porous Conduits - Research Website

A professional research website showcasing investigations into shock wave behavior in porous-walled conduits.

## Overview

This website presents research on the influence of porous wall internal geometry on shock wave propagation and behavior within conduits. The research is conducted at the Technion - Israel Institute of Technology.

## Research Topic

**The Influence of Porous Walls Internal Geometry on the Behavior of Shock Waves Moving Inside a Conduit**

This project investigates how the structural properties of porous walls affect shock wave dynamics, with applications in:
- Combustion systems and detonation engines
- Industrial safety equipment
- Material science and acoustic engineering
- Protective systems against shock waves

## Website Structure

The website consists of 5 main pages:

1. **Home (index.html)** - Landing page with research overview

## Deployment Options (Making it Accessible to Anyone)

### Option 1: GitHub Pages (Recommended - Free & Easy)
1. Push this repository to GitHub
2. Go to repository Settings → Pages
3. Set source to "main" branch
4. Your site will be available at `https://yourusername.github.io/Ai_course_website`

### Option 2: Netlify (Free)
1. Create account at netlify.com
2. Drag and drop the project folder
3. Gets a live URL automatically
4. Very easy for static sites

### Option 3: Vercel (Free)
1. Import the repository from GitHub at vercel.com
2. Deploy automatically
3. Gets a live domain

### Option 4: Web Server (Advanced)
- Upload files via FTP to any web hosting service
- Use Apache, Nginx, or any static server
- Configure your domain

### Option 5: Local Server (Development)
